Frontend and mobile engineer based in **Konya, Türkiye**. I design and ship production software across **web, iOS, and Android**, with a focus on clean architecture, reactive state, and interfaces that stay fast under live data.

## Experience

### SadaApex — Frontend & Mobile Developer
`Sep 2025 — Oct 2026` · FinTech · iOS & Android

Designed and shipped a production mobile app for realtime crypto technical analysis with **Flutter, Riverpod, and Clean Architecture**.

- Built a custom **Flutter Canvas chart engine**: pan, zoom, dynamic crosshair, **80+ indicators**, and **90+ interactive drawing tools**
